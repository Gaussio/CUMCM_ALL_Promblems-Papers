# 机器人避障问题

## 摘 要

本文是机器人避障路线设计问题，要求我们建立机器人从区域中一点到达另一点的避障最短路径和最短时间路径的数学模型。

针对问题一，为使机器人不与障碍物碰撞，在原障碍物的边界向外延伸 10个单位，并在顶点处以半径为10 个单位向外做圆，形成一条机器人行走的“安全路径”，即机器人可以贴着“安全路径”行走。

首先，通过证明可以在众多的行走路线中适当减少些路径，再由这些潜在的最短路径，利用图论的知识对其进行最短路径的求解，通过 Floyd 算法得到机器人从 O(0, 0)出发， O→A、O→B、O→C 和O→A→B→C→O 的折线最短距离分别为：471.041 、853.088 、1092.819、2716.431 折线最短总时间分别为：96.018、179.241、233.329、568.318。然后，对模型一进行优化，考虑机器人圆弧转弯路径，通过定理的证明可知在半径最小时并把拐弯圆弧的圆心定在各个端点。运用几何定理对每段最短路径分段处理，联立方程组建立模型二，利用 lingo12 求解各切点即每次的起点与终点坐标。最后，利用matlab7.0求解直线和弧长及行走时间（结果见表五至表八）。

针对问题二，求解 到A的最短时间路径，此时最短时间与最短线路、最短线路上拐弯次数以及拐弯半径的大小有关，由拐弯半径与速度的函数关系式：$\nu = \nu ( r ) = 5 / ( 1 + e ^ { 1 0 - 0 . 1 r ^ { 2 } } )$ 用 matlab7.0 绘制图像分析和探讨可知：在半径满足时，机器人拐弯速度趋近极大值 。所以，在一定的半径范围之内，速度不再是限制时间最小的约束条件，那么最短时间的确定就可以转化成最短路径的求解。因此，在拐弯时速度不再发生改变时，半径越小对最短拐弯时间越有利。对于怎么样去确定合适的半径使得行走的时间最短，我们利用问题一中求解的由O到 的最短线路中切点的坐标来确定模型三中机器人行走直线段的方程。并利用题目的数据及相关的限制条件对问题二建立非线性目标规划的搜索模型，并利用 lingo对其进行搜索，从而找到最合适半径 $r = 1 3 . 1 8 8 7$ 以及此时对应的拐弯圆弧的圆心坐标 。随着拐弯半径及圆心的改变会使得搜索出来路径中的切点发生改变得到两切点坐标为$T _ { \scriptscriptstyle 3 } ( 7 2 . 8 3 2 , 2 1 1 . 0 3 8 )$ 、 ，此时机器人拐弯行走路程的最短时间为：T = 94.2182 (s) 。

关键词： 机器人避撞 图论 Floyd算法 非线性目标规划 最佳半径

## 二 问题分析

问题一：求解两点之间通过拐弯来避免碰撞的最短路径。可以利用图论中的有关模型对其进行求解，考虑到障碍物之间有多条路径，这对模型的建立与求解增加了很大的难度。所以，首先我们通过一些简单定理的证明，从所有的路径中找到潜在的最短路径。从而通过图论确定最短路径的折线走法。对于具体拐弯路径的确定，由有关定理知，以半径为 10 作为所有拐弯的拐弯半径，是最佳拐弯半径。并以各个已知的节点坐标作为拐弯圆弧的圆心。由此，得到 O→A、O→B、O→C 和O→A→B→C→O 的最短路径及

总用时间。

问题二：要求解最短时间的路径，其路径并不是等于问题一中的最短路径，但是可以借助其最短路径中切点的坐标来确定最短时间路径的直线方程。接下来就是怎么样寻找两条直线间用时最短的圆弧，也就是对于圆弧圆心以及半径的确定，又由拐弯速度与拐弯半径的关系表达式知道最佳拐弯半径的一定范围。由此，我们可以借助已有的条件建立非线性的目标规划模型，利用 lingo的搜索功能进行求解。

## 三 模型假设

为了使得模型便于建立和求解，我们对模型提出了如下的假设：

1.目标点与障碍物的距离至少超过 10个单位；  
2.机器人在可行进范围内的道路平坦，不会出现其他细微因素对机器人行走造成不必要的影响；  
3.不计机器人的能量消耗；  
4.不计机器人由于转向或者变速所产生的时间消耗；  
5.机器人在直线路径中始终保持最大速度 $\mathrm { V } _ { 0 } = 5$ 个单位/秒的速度做匀速运动；  
6.机器人在转弯路径中始终保持最大速度 $\nu = \nu ( \rho ) = \frac { \nu _ { 0 } } { 1 + \mathrm { e } ^ { 1 0 - 0 . 1 \rho ^ { 2 } } }$ 做匀速运动；

## 七 模型的评价与推广

1、本文通过对机器人避障问题的全面考虑，对于折线转弯理想模型我们引入绕障碍物线性探索最短路径定理，接着引入凸集最短路定理对实际转弯模型进行科学合理的优化，为最短路模型的逐步筛选提供了科学可靠的理论依据。在科学合理的理论基础上对所有可行路线进行筛选，大大缩小了计算量，提高了计算效率，可以很好的确保结果的准确度。  
2、对于问题一，找到达指定目标点的最短路径和时间，本文将路线图转化为网络图，运用图论知识求解最短路径和最短时间，采用 floyd算法逐步优化建立模型。这中网络图形转换法在很多领域都可以得到很好的推广与实践，如：管道运输问题、交通道路选择问题等。  
3、在最短路优化模型的建立中，我们以逐步优化、分段处理的方法，在找到折线最短路的基础上进一步优化，利用几何定理对每一段最短路进行计算求解，思路清晰，方法通俗易懂，但对于大规模的网络具有一定得局限性。
